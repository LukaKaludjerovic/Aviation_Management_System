# Intelligent AMOS System (Aircraft Maintenance and Operational System)

Fully functional AMOS System for commercial airlines written in C# and Flutter. 

The project features include:
* Mobile devices compatibility
* Creating maintenance logs and receipts
* Managing aircraft in the fleet
* Managing routes and destinations
* Intelligent predictions about flight time for route
* Intelligent predictions about maintenance duration

# How to run the project

* Open ./aerosense-api/aerosense-api.sln
* Run server with dotnet run
* Open ./aerosense-mobile
* Run mobile app with flutter run
